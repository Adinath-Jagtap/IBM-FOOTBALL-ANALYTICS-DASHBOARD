# Football Player Performance Analytics Dashboard

> **Data notice:** All player statistics are **synthetic** and do **not** represent real-world football results.

An interactive, portfolio-quality football (soccer) analytics dashboard built with Python and Streamlit. Analyse and compare player performance across teams, positions, and seasons using rich Plotly visualisations and a dark, football-inspired UI.

---

## Features

| # | Feature |
|---|---------|
| 1 | **Overview** — five KPI cards (total players, goals, assists, minutes played, avg rating) + three summary charts |
| 2 | **Player Analysis** — radar comparison chart (up to 4 players), goals vs assists scatter, shots vs goals scatter with trend line |
| 3 | **Team Analysis** — goals & assists grouped bar, player count, average rating per team |
| 4 | **Position Analysis** — box plots, violin charts, and grouped bars for GK / DEF / MID / FWD |
| 5 | **Sidebar Filters** — filter by season, team, position, and player name search |
| 6 | **Searchable Stats Table** — full player statistics with in-table name search |
| 7 | **CSV Download** — one-click download of the currently filtered dataset |
| 8 | **Dark Football UI** — green pitch theme, custom metric cards, Plotly dark charts |
| 9 | **Input Validation** — empty-filter warnings, missing-value detection, file-not-found error |

---

## Tech Stack

- **Python 3.11+**
- **Streamlit** — web app framework
- **Pandas / NumPy** — data manipulation and generation
- **Plotly Express & Graph Objects** — interactive charts
- **statsmodels** — OLS trend line for scatter chart

## Dataset

The dataset is **fully synthetic**, generated by `generate_data.py` using `numpy.random.seed(42)` for reproducibility.

| Property | Value |
|----------|-------|
| Total rows | 480 |
| Unique players | 160 |
| Teams | 8 |
| Seasons | 2021-22, 2022-23, 2023-24 |
| Positions | GK, DEF, MID, FWD |
| Columns | 20 |

All records carry a `data_source = "Synthetic — not real-world data"` column.

## Getting Started (Local)

### 1. Clone / download the project

```bash
git clone <your-repo-url>
cd IBM
```

### 2. Create a virtual environment (recommended)

```bash
python -m venv venv

# Windows
venv\Scripts\activate

# macOS / Linux
source venv/bin/activate
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Generate the dataset (already committed, but regenerate if needed)

```bash
python generate_data.py
```

### 5. Run the app

```bash
streamlit run app.py
```

The dashboard opens automatically at `http://localhost:8501`.

---

## Deployment — Streamlit Community Cloud

1. Push the project to a public GitHub repository.
2. Go to [share.streamlit.io](https://share.streamlit.io) and sign in with GitHub.
3. Click **New app** → select your repository → set **Main file path** to `app.py`.
4. Click **Deploy**.

> Streamlit Cloud reads `requirements.txt` automatically. The `football_players.csv` must be committed to the repository so the app can load it on the cloud.
